# Cahier des charges — renvoi

Le cahier des charges complet n'est pas dupliqué ici. Il se trouve dans le projet Claude « Github School Manager PRO » :
- « Memoire 3 » : ordonnance d'exécution technique et fonctionnelle (exigences, modules, phases 0 à 9).
- « Memoire » : directives générales de collaboration et d'exécution.

Règles métier permanentes à rappeler ici :
- Le site (logo, nom, slogan) ne se modifie que par le superadmin.
- Chaque établissement gère son propre compte, ses sous-comptes, son logo de documents, son affiche et ses textes, dans les limites de son contrat.
- Un administrateur local ne peut jamais activer un module que le contrat ne prévoit pas.
- Les données d'un établissement ne sont jamais visibles d'un autre.
